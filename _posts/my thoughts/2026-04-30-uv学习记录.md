# uv工具介绍

是一个python包和项目管理工具。目标是用一个工具替代 `pip`、`virtualenv`、`pip-tools`、`poetry`、`pyenv` 等传统 Python 工具链，让依赖管理、环境创建、项目发布都变得又快又省心。相较于conda，是完全开源的。

# 安装

```
# On macOS and Linux.
curl -LsSf https://astral.sh/uv/install.sh | sh

# On Windows.
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# With pip.
pip install uv
```

安装完成后，可用uv help检查是否安装成功。如果显示未识别，但前面安装显示成功；可能是由于环境变量未更新的原因，需要关闭终端窗口重新打开。

# 项目构建

- 新建文件夹后，在文件夹内使用`uv init`，或者使用直接使用`uv init project`。
- 终端输入`uv sync`同步项目依赖。
- 可以使用`uv add [包名]`添加依赖，使用`uv remove [包名]`删除依赖。
