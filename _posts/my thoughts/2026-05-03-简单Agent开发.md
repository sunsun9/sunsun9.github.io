# 说明

- 参考[github开源项目](https://github.com/lasywolf/Learn-OpenClaw/tree/main)实现了一个可以调用工具的简单Agent，并在这个基础上接入了飞书。
- 运行流程：
    1. 本地启动Agent。如果需要后端一直开启的话，可以加上PM2管理。
    2. 在飞书上创建一个Agent即可，需要使用ngrok获取一个公网地址（启动：ngrok http 3000）。
    3. 打开飞书，即可使用。

- 注意点：
    1. 飞书在配置http的时候，需要先开启后端，否则会显示返回数据不是json格式。
